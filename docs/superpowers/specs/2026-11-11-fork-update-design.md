# Настройка самостоятельного форка

Удалить синхронизацию через Яндекс Диск, сохранив Google Диск и остальные функции. Данные в облаке не удалять.

Проверять обновления исключительно через GitHub Releases `thejohnd0e/AudioBooks`, сохранив автоматическое расписание, ручную проверку и проверку хеша, пакета, версии и подписи. Не обращаться к источникам обновлений оригинала.

В «О программе» удалить ссылки на 4PDA и Telegram, ссылку GitHub заменить на репозиторий форка, адрес обратной связи — на `android-dev@intertop.link`, текст ручной проверки — на «Проверить обновление».

Рассмотренные варианты: заменить только адрес GitHub с сохранением зеркал оригинала либо убрать все источники оригинала. Выбран второй, чтобы не предлагать чужие сборки.

Собрать и проверить APK, не затрагивая существующие пользовательские изменения и данные. Публикацию релиза проводить только после проверки версии, подписи, готовности GitHub и отдельного подтверждения владельца.
