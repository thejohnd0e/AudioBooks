# Modern Polish (Вариант В) — дизайн каталога и ключевых экранов

**Дата:** 11 ноября 2026  
**Ветка:** `feature/modern-polish-v2`  
**Статус:** на одобрение, ничего не zmienяно в коде

## Intent / почему

Приложение AudioBooks работает на Java + XML, архитектура источников не меняется. Пользователь просит "посовременнее", выбрав вариант **В**: отполировать текущий каталог без смены архитектуры, без Compose/Kotlin, без новых веток по доменам в presenters/player/download.

Цель — освежить внешний вид: больше воздуха, современные акценты, скруглённые карточки, чище типографика, аккуратные чипы фильтров и источников. Данные пользователя, навигация, парсеры, сохранённые ID и préférences не трогаются.

## Goals

- Обновить цвета: тёмная тема по умолчанию, один акцентный цвет, лучше читаемый второстепенный текст.
- Карточки книг: скругленные углы, elevation/тень, больше отступов, источник как чип.
- Чипы фильтров и источников: аккуратный Material-вид.
- Плеер: обложка крупнее, иерархияタイトル/автора/глав понятнее (дополняет уже запланированный план обложек).
- Никаких изменений в Java-логике, навигации, источниках, Room- esquema, данных пользователя.

## Non-goals

- Не переходить на Compose/Kotlin.
- Не менять структуру экранов, навигацию, пункты меню.
- Не трогать парсеры, `Provider`, источники, сетевой слой.
- Не менять Room-сущности, миграции, сохранённые пользовательские данные.

## Constraints

- Java + XML только. Дизайн ложится на существующие `colors.xml`, `styles.xml`, `dimens.xml`, layout-файлы.
- Ветка `feature/modern-polish-v2`, коммит и push — только по запросу владельца.
- Одна сборка Gradle за раз, без `clean`, без эмулятора/без `adb` (по правилам CLAUDE.md).

## Approaches (raссмотрены)

1. **А — Material You (динамические цвета, тёмная/светлая тема)** — отброшен: больше работы с темами, выходит за рамки "полировки текущего".
2. **Б — Тёмный кинотеатр** — отброшен: слишком резкое изменение, пользователь выбрал В.
3. **В — Отполированный текущий каталог** (выбран): эволюция существующих цветов, скруглений, чипов и типографики. Минимум риска, заметное обновление.

## What changes (предлагаемые файлы)

- `app/src/main/res/values/colors.xml` — акцентированный цвет, фон, второстепенный текст, цвета тёмной/светлой темы.
- `app/src/main/res/values/styles.xml` — стили карточек, чипов, toolbar.
- `app/src/main/res/layout/books_recycler_item.xml` — скруглённая карточка с фоном и отступами.
- `app/src/main/res/layout/player.xml` — более крупная обложка, яснее иерархия (дополняет запланированный план обложек).
- Возможно `app/src/main/res/layout/app_bar_main.xml`, `content_main.xml`, `fragment_books.xml` — отступы и чипы.
