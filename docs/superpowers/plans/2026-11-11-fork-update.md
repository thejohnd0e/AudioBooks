# Fork update implementation plan

**Goal:** Убрать синхронизацию Яндекс и источники обновлений оригинала, настроить контакты форка и собрать APK.

**Architecture:** Сохранить существующий механизм синхронизации Google и проверку подлинности APK. В обновлениях оставить GitHub форка и существующие сетевые маршруты без резервных сайтов оригинала.

**Tech Stack:** Android Java, Gradle, JUnit.

**Spec:** `docs/superpowers/specs/2026-11-11-fork-update-design.md`

## Global Constraints
- Не менять другие функции, не удалять пользовательские данные, не запускать clean или эмулятор.
- Сохранить пользовательские изменения `app/build.gradle`; не коммитить и не публиковать без отдельного разрешения.
- Одновременно запускать только одну сборку Gradle.

## Review Focus
- Недоступный GitHub: ошибка проверки, не обращение к прежним источникам.
- Отсутствующий релиз или контрольная сумма: ошибка без предложения APK.
- Несовпадающие пакет, версия, подпись или хеш: APK отклоняется.
- Google-синхронизация остаётся доступной; облачные файлы не удаляются.
- Периодические и ручные проверки продолжают работать.

### Task 1: Синхронизация и меню
**Files:** `sync/CloudSync.java`, `sync/YandexDisk.java`, `app/build.gradle`, `gradle.properties`, `app/proguard-rules.pro`, `fragment/AboutFragment.java`, `res/xml/about_preferences.xml`, `res/values/strings*.xml`, `docs/cloud-sync.md`.
- [ ] Добавить проверки отсутствия Яндекс-сервиса и нужных пунктов меню; проверить их отказ до изменения.
- [ ] Убрать регистрацию и зависимости Яндекс-синхронизации, не затрагивая Google; обновить контакт, ссылку и меню.
- [ ] Обновить документацию и выполнить соответствующие тесты.

### Task 2: Обновления форка
**Files:** `update/Updater.java`, `update/UpdateSources.java`, `activity/MainActivity.java`, тесты `update/UpdateSourcesTest.java`, документация релизов.
- [ ] Добавить тесты адресов форка и отсутствия обращения к старым источникам, отказа при недоступном GitHub и сохранения проверки релиза; проверить отказ тестов до изменения.
- [ ] Оставить GitHub Releases форка и сетевые маршруты, убрать цепочку зеркал и форума; сохранить проверки скачанного APK и расписание.
- [ ] Запустить тесты и обновить документацию релизов.

### Task 3: Проверка и сборка
- [ ] Последовательно выполнить `:app:testDebugUnitTest`, `:app:lintDebug`, `:app:assembleDebug` и при необходимости собрать пользовательский APK с подходящей подписью.
- [ ] Проверить пакет, версию, сертификат и совместимость с ранее выданными APK; сохранить существующие APK.
- [ ] Проверить настройки выпуска и сообщить владельцу условия и риски публикации; публичные действия только с разрешения.
